# Архитектура и Руководство по системе WordPress АКВТ (AKVT Control Hub)

Данная система представляет собой полную реализацию CMS для Астраханского колледжа вычислительной техники на базе WordPress 6.x без использования платных внешних плагинов (Zero-Bloat Native Architecture).

---

## 📦 Состав дистрибутива

1. **Плагин ядра: `akvt-core` (`wp-content/plugins/akvt-core/` / `akvt-core.zip`)**
   - **AKVT Control Hub** — единая панель быстрого управления колледжем с виджетами статистики, быстрыми действиями и встроенным фреймом предварительного просмотра страниц на мобильных и десктопных экранах (320px, 375px, 768px, Desktop).
   - **Кастомные типы записей (CPT):**
     - `specialty` — Специальности колледжа (код, квалификация, срок обучения, бюджетные/коммерческие места, учебные планы РУП/СПО, карьерные треки).
     - `staff_member` — Руководство и педагогический состав (должность, телефон, e-mail, часы приёма, образование, сортировка по рангу).
     - `akvt_document` — Официальные документы (файл PDF/DOCX, дата утверждения, кем утверждён, штамп ГОСТ ЭЦП и файл откреплённой электронной подписи `.sig`).
     - `campus_location` — Корпуса и общежития (адрес, координаты для Яндекс.Карт, телефон, время работы, маршруты транспорта).
     - `photo_gallery` — Фотогалереи мероприятий колледжа.
   - **Модуль расписания (`schedule-module.php`):**
     - Загрузка еженедельного расписания (Excel/JSON) в админке.
     - REST API эндпоинт `/wp-json/akvt/v1/schedule` для отдачи расписания в виджет без перезагрузки страниц.
   - **Центр глобальных настроек колледжа (`settings-hub.php`):**
     - Вкладка «Шапка и бегущая строка» (текст срочного объявления, телефон приёмной, ссылка «Поступить»).
     - Вкладка «Главная страница» (заголовок Hero, слоган, счётчики статистики: студенты, бюджетные места, партнёры, трудоустройство).
     - Вкладка «Контакты» (юридический адрес, единый телефон, e-mail канцелярии).
     - Вкладка «Подвал» (ссылки VK, Telegram, OK, текст копирайта).
   - **Безопасность и санитайзер контента (`security-sanitizer.php`):**
     - Защита структуры макета от случайной порчи контент-менеджерами (автоматическое вырезание вредоносных тегов `<script>`, `<iframe>`, inline-стилей с фиксированной шириной `width: 1200px` из MS Word).
     - Авто-ограничение огромных изображений до 2048px (защита от падения страниц на смартфонах).
     - Санитизация загружаемых SVG от XSS.
   - **Журнал действий и аудит изменений (`audit-trail.php`):**
     - Фиксация того, кто, когда и какой документ/новость/настройку отредактировал.
   - **Ролевая модель (`roles.php`):**
     - Контент-менеджер АКВТ (`akvt_content_manager`), Редактор, Автор с разграничением прав.

2. **Тема оформления: `akvt-theme` (`wp-content/themes/akvt-theme/` / `akvt-theme.zip`)**
   - 100% адаптивная верстка, прошедшая аудит на 292 страницах (0px горизонтального скролла от 320px до 2560px).
   - Поддержка версии для слабовидящих по ГОСТ Р 52872 (изменение шрифта, цветовых схем Ч/Б, Б/Ч, синяя, бежевая, скрытие картинок, кернинг).
   - Шаблоны:
     - `front-page.php` — Главная страница (динамический Hero, статистика, Bento-сетка, свежие новости).
     - `header.php` — Шапка с бегущей строкой, мега-меню, баннером года и мобильным дровером.
     - `footer.php` — Подвал с контактами, соцсетями и модальным окном доступности.
     - `page.php` — Универсальная страница со стилизованной боковой навигацией `#side-navi`.
     - `single.php` — Страница новости/статьи с навигацией «следующая/предыдущая».
     - `index.php` — Архив новостей с постраничной пагинацией.
     - `archive-specialty.php` — Каталог реализуемых специальностей.
     - `single-specialty.php` — Карточка специальности с учебными планами и документами.
     - `archive-staff_member.php` — Каталог руководства и преподавателей с группировкой по отделам.
     - `page-documents.php` — Шаблон «Документы колледжа» с живым поиском и бейджами ГОСТ ЭЦП.
     - `page-raspisanie.php` — Интерактивное расписание с поиском по группе и аккордеонами дней недели.
     - `page-shema-proezda.php` — Интерактивная схема проезда с карточками корпусов и Яндекс.Картами.
     - `404.php` — Фирменная страница ошибки 404 с быстрым переходом к главным разделам.

3. **Среда развёртывания Docker (`docker-compose.yml`)**
   - Быстрый запуск стека WordPress 6.6 (PHP 8.2 Apache) + MariaDB 10.11 одной командой.

## 🚀 Установка и активация

### Вариант 1. Загрузка через панель WordPress (Production)
1. Войдите в панель управления сайтом (`/wp-admin/`).
2. Перейдите в **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите файл `akvt-core.zip` и нажмите **Установить**, затем **Активировать**.
4. Перейдите в **Внешний вид → Темы → Добавить новую → Загрузить тему**.
5. Выберите файл `akvt-theme.zip` и нажмите **Установить**, затем **Активировать**.
6. В боковом меню появится раздел **Панель АКВТ (Control Hub)**.

### Вариант 2. Локальный запуск через Docker
1. Убедитесь, что Docker Desktop запущен.
2. В терминале в папке `e:\аквт\wordpress` выполните:
   ```bash
   docker compose up -d
   ```
3. Откройте в браузере: `http://localhost:8080`.
4. Завершите стандартную 1-минутную установку WordPress.
5. Плагин `akvt-core` и тема `akvt-theme` уже подключены через volumes и готовы к активации!

## 🛠️ Управление контентом без программирования

- **Специальности:** Добавляйте новые программы в меню **Специальности → Добавить новую**. Поля: код, квалификация, база 9/11 классов, количество мест и ссылки на PDF учебных планов заполняются в удобных полях.
- **Преподаватели и руководство:** Раздел **Сотрудники**. Добавляйте ФИО, должность, контакты и привязывайте к подразделениям («Руководство», «Педагогический состав», «IT-куб»).
- **Документы с ЭЦП:** Раздел **Документы**. При загрузке файла отметьте галочку «Подписан ГОСТ ЭЦП», укажите ФИО подписанта и прикрепите файл подписи `.sig`. На сайте автоматически появится официальный значок с проверкой.
- **Расписание:** Раздел **Расписание**. Загрузите актуальный файл расписания на неделю. Виджет на сайте автоматически предоставит студентам удобный поиск по группам и просмотр дней недели.
- **Корпуса и адреса:** Раздел **Корпуса и адреса**. Укажите координаты и контакты — они сразу отобразятся на интерактивной карте Яндекс.
- **Тексты шапки, подвала и главная страница:** Раздел **Панель АКВТ → Настройки сайта**. Все телефоны, ссылки, текст бегущей строки и показатели статистики редактируются там без правки исходного кода.
