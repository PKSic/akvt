**Версия:** 2.2 (React 18 News Hub + Мульти-рубрики и теги + Vercel & Local Server)  
**Дата актуализации:** Ноябрь 2026 г.

## 4. Использование JS-фреймворка React (React 18)

Для соответствия критерию **«Использование клиентского JS-фреймворка (React)»** в проект интегрирован реактивный модуль:

1. **Зависимости в `package.json`:**
   ```json
   "dependencies": {
     "react": "^18.3.1",
     "react-dom": "^18.3.1"
   }
   ```
2. **Архитектура React-компонента (`site/js/react-news-hub.js`):**
   * Корневой компонент: `ReactNewsHubApp`.
   * Хуки React 18:
     * `useState`: состояние активной рубрики, тега, строки поиска, порядка сортировки и списка статей.
     * `useMemo`: моментальная фильтрация массива новостей (130+ записей) на лету без задержек; подсчёт количества новостей в рубриках и построение облака тегов.
     * `useEffect`: загрузка данных из базы `pages-index.json` с механизмом автоматического DOM-fallback при офлайн-работе.
     * `useCallback`: оптимизированные функции сброса и переключения тегов.
3. **Возможности React-интерфейса на сайте:**
   * **Мульти-рубрикация:** кнопки-пилюли с живым счетчиком статей в каждой категории (*«Все новости»*, *«Новости АКВТ»*, *«IT-Куб»*, *«Студентам»*, *«Абитуриентам»*, *«Мероприятия»*, *«Объявления»*, *«Спорт»*, *«Достижения»*).
   * **Облако тегов:** кликабельные плашки тегов (*`#Хакатон`*, *`#Конкурс`*...). Клик по тегу на любой карточке моментально фильтрует список.
   * **Живой мгновенный поиск:** фильтрует карточки при вводе любого слова с кнопкой очистки `×`.
   * **Сортировка:** переключение «Сначала новые» / «Сначала старые».
   * **Сетка карточек:** адаптивные карточки со ссылками на страницы статей, датами и бейджами категорий.
4. **Где посмотреть в онлайне:**
   * Открыть: [https://akvt-xi.vercel.app/news/](https://akvt-xi.vercel.app/news/) или [https://akvt-xi.vercel.app/archives/](https://akvt-xi.vercel.app/archives/).
   * Внизу блока отображается значок: `⚛️ React Component (v18.3.1)`.
   * В консоли разработчика (F12) пишется: `[React News Hub] Успешно смонтирован React-компонент (React v18.3.1)`.
   * В расширении **React Developer Tools** отображается живое дерево компонентов React.

## 5. Публикация новостей с множественными рубриками и тегами

* **В интерфейсе админки (`#/new-news`):**  
  [https://akvt-xi.vercel.app/admin/#/new-news](https://akvt-xi.vercel.app/admin/#/new-news)  
  Доступен одновременный выбор галочками любых рубрик (*Новости АКВТ*, *IT-Куб*, *Студентам* и др.) и поле ввода произвольных тегов через запятую (например: `Хакатон, Робототехника`).
* **Что происходит физически при публикации:**
  1. Создается файл статьи: `site/ГГГГ/ММ/ДД/<slug>/index.html` с цветными плашками выбранных рубрик и тегов.
  2. Статья одновременно вносится в списки **всех** выбранных рубрик (`site/category/<slug>/index.html`).
  3. Статья вносится в общий хронологический архив `site/archives/index.html` и в `sitemap.xml`.
  4. Если выбрана рубрика «Новости АКВТ» — статья автоматически попадает в блок свежих новостей на главной странице (`site/index.html`).
  5. Статья автоматически отображается в интерактивном **React News Hub**.

## 6. Два режима работы: Онлайн (Vercel) и Локальный (Offline)

### Режим 1: Онлайн на Vercel (через GitHub)
* При выполнении `git push origin main` Vercel автоматически собирает и публикует проект за ~30–45 секунд.
* Все страницы мгновенно доступны по адресу [https://akvt-xi.vercel.app/](https://akvt-xi.vercel.app/).
* Админка в онлайне [https://akvt-xi.vercel.app/admin/](https://akvt-xi.vercel.app/admin/) позволяет публиковать материалы прямо в репозиторий через Fine-Grained токен GitHub.

### Режим 2: Локальный автономный режим (без интернета и GitHub)
* Запуск через **`Запустить_админку.bat`** или **`Запустить_сайт.bat`** (или `node server.mjs`).
* Сервер работает на порту `8790`.
* В админке достаточно нажать зеленую кнопку **«Войти локально (сохранение на диск)»** — все сохранения пишутся сразу в локальные файлы на вашем компьютере.
* Защита от прямого клика по `file://`: при открытии файла `index.html` браузер показывает карточку-подсказку и автоматически перенаправляет на `http://localhost:8790/admin/`, как только сервер запускается.

## 7. Регламент работы с файлами

| Задача | Как выполнять |
|---|---|
| **Создание/правка страниц и новостей** | **Только через админ-панель.** Админка сама пересчитывает ссылки, обновляет архивы и sitemap. |
| **Редактирование меню сайта** | Через вкладку **«Меню сайта»** в админке (шапка синхронизируется на всех страницах одним кликом). |
| **Загрузка PDF и картинок** | Через вкладку **«Файлы и картинки»** или прямо из визуального редактора статьи. |
| **Правка React-компонента** | В файле `site/js/react-news-hub.js` и стилях `site/css/react-news.css`. |
| **Правка CSS стилей сайта** | В файлах `site/css/global.css` и `site/css/style.css`. |
| **Правка пасхалок** | В файлах `site/js/main.js` и `site/js/runtime.js`. |
| **Файл `admin/pages-index.json`** | Вручную не редактировать (обновляется админкой автоматически). |
