# Проект сайта АКВТ (Астраханский колледж вычислительной техники)

Структура репозитория:

* **`/site`** — Основной публичный сайт колледжа (статическая сборка, адаптивная вёрстка, стили, медиатека, расписание).
* **`/admin`** — Панель управления контентом колледжа (Admin Control Hub) для редактирования специальностей, преподавателей, документов, расписания и глобальных настроек.
* **`/wordpress`** — Официальная тема `akvt-theme` и плагин ядра `akvt-core` для интеграции с WordPress.
