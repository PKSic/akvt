# Админ-панель АКВТ

Открывается по адресу `https://<ваш-сайт>/admin/`. Работает без сервера: правит файлы сайта прямо в репозитории GitHub
через токен доступа, а Vercel публикует изменения сам (обычно за минуту).

## Первый вход
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access → *Only select repositories* → репозиторий сайта (`PKSic/akvt`).
3. Permissions → Repository permissions → **Contents: Read and write**. Больше ничего не нужно.
4. Вставьте токен на странице входа. «Запомнить на этом устройстве» хранит его в браузере (localStorage).

## Что умеет
| Раздел | Что делает при сохранении |
|---|---|
| Страницы | правка текста/картинок/ссылок/таблиц, заголовок и описание; создание страницы в любом разделе (добавляется в боковое меню раздела, карту сайта, sitemap.xml); удаление |
| Новости | создание новости: страница + главная (6 свежих) + «Все новости» + рубрики + sitemap; правка и удаление |
| Меню сайта | пункты и подпункты шапки (ПК и телефон) — обновляет шапку на всех страницах одним коммитом |
| Контакты и подвал | телефоны, адрес, e-mail, соцсети, строка в шапке — на всех страницах |
| Файлы | загрузка PDF/картинок в `site/wp-content/uploads/ГГГГ/ММ/`, удаление |
| Расписание | замена файлов `.xls` расписания |
| Проверка ссылок | находит битые внутренние ссылки и картинки |
| История | коммиты; у страницы — загрузка прежней версии в редактор |

## Файлы
- `index.html`, `app.mjs`, `editor.mjs`, `ui.mjs`, `admin.css` — интерфейс.
- `core.mjs` — чистые функции правки HTML (точечные замены, остальной файл не трогается).
- `ops.mjs` — операции: что и в каких файлах менять.
- `github.mjs` — запись в GitHub одним коммитом (Git Data API).
- `pages-index.json` — список страниц (заголовки, адреса, даты новостей). Обновляется админкой при создании/удалении/переименовании.
  Если страницы правились мимо админки: `node admin/build-index.mjs` из корня репозитория.
- `legacy-prototype.html` — старый макет интерфейса (ничего не сохранял), оставлен для справки.
- `test/` — проверки: `selftest.mjs` (логика на копии репозитория), `e2e.py` + `dev-server.mjs` (браузерный тест с поддельным GitHub API).

## Ограничения
- Доступ определяется токеном. Дать доступ другому человеку — добавить его в репозиторий (Collaborators), у него будет свой токен.
- Одновременно правьте одну страницу одному человеку: сохранение перезаписывает файл целиком.
- Формы заявления/обращений и скрипты сайта в админке не настраиваются.
